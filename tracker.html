REAL DATA • JAVA ENGINE

Connect FocusFlow to your real digital behaviour.

A normal website cannot read Windows application usage because browsers intentionally isolate that data. FocusFlow solves this with a small Java Windows agent and a Chrome/Edge extension. The website, backend and database remain Java/Spring Boot + MySQL.

1 · Start MySQL

CREATE DATABASE focusflow;

2 · Start the Java backend

D:\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run

Default URL: http://localhost:8081

3 · Start the Java Windows agent

cd windows-agent-java
D:\apache-maven-3.9.16\bin\mvn.cmd clean package
java -jar target\focusflow-windows-agent-1.0.0.jar

4 · Install the browser companion

Chrome/Edge → Extensions → Developer mode → Load unpacked → select the browser-extension folder.

5 · Enable live YouTube transformation

Create a YouTube Data API v3 key and set:

$env:YOUTUBE_API_KEY="YOUR_KEY"
D:\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run

Without a key FocusFlow stays honest and does not invent YouTube data.
